# 黑盒行为清单

只写「用户做什么 → 应该看到什么」，不涉及实现。每条都要能被 e2e 自动验证，
标 `[手动]` 的是需要外网、剪贴板权限或人工判断的，标 `[已知降级]` 的是当前实现不支持的。

编号即 e2e 里的用例名。

## A. 初始化

| # | 操作 | 预期 |
|-|-|-|
| A1 | 打开页面 | 左栏、画布、工具栏、右下浮圆都在 |
| A2 | 打开页面 | 画布显示欢迎内容「Hello，欢迎使用VCC编辑器」 |
| A3 | 打开页面 | 控制台无未捕获异常 |
| A4 | 打开页面 | 默认停在原生标签库 |

## B. 左栏：组件库切换（7 个图标）

| # | 操作 | 预期 |
|-|-|-|
| B1 | 点 Element 图标 | 出现分类导航（默认按钮/朴素按钮/…/表格/分页/表单） |
| B2 | 点 Element 图标 | 示例区出现可拖按钮 |
| B3 | 点 Vant 图标 | 分类变成 单元格/图标/图片/输入框/… |
| B4 | 点 AntD 图标 | 分类只有 按钮、按钮组 |
| B5 | 点 ECharts 图标 | 显示图表示例 |
| B6 | 点 iView 图标 | 无反应（原版即禁用） |
| B7 | 点 Quasar 图标 | 无反应（原版即禁用） |
| B8 | 切换后 | 被点的图标高亮，上一个取消高亮 |

## C. 左栏：搜索与分类导航

| # | 操作 | 预期 |
|-|-|-|
| C1 | 搜索框输入组件名 | 出现匹配建议 |
| C2 | 选中建议 | 示例区滚动到该组件 |
| C3 | 点分类项 | 示例区滚动到对应分组，该分类高亮 |

## D. 拖拽（核心链路）

| # | 操作 | 预期 |
|-|-|-|
| D1 | 示例区元素拖到画布空白 | 画布新增该节点 |
| D2 | 拖到容器中部 | 作为该容器的子节点追加 |
| D3 | 拖到节点上沿 | 插到该节点之前 |
| D4 | 拖到节点下沿 | 插到该节点之后 |
| D5 | 拖到不接受子节点的组件中部 | 退化为插到其后，不报错 |
| D6 | 拖动画布内已有节点 | 节点位置变化，同级节点数不变 |
| D7 | 拖拽悬停时 | 落点有视觉提示 |

## E. 画布选中

| # | 操作 | 预期 |
|-|-|-|
| E1 | 点节点 | 该节点出现选中框 |
| E2 | 点画布空白 | 选中被清除 |
| E3 | 鼠标悬停节点 | 出现虚线提示 |

## F. 属性面板

| # | 操作 | 预期 |
|-|-|-|
| F1 | 未选中 | 面板停在屏幕外 |
| F2 | 选中节点 | 面板从右侧滑出 |
| F3 | 选中节点 | 列出该节点的 key/value 行 |
| F4 | 改 value 后点保存 | 画布随之更新 |
| F5 | 点某行减号 | 该属性被删除 |
| F6 | 点 + 填 key/value | 新属性出现在行列表 |
| F7 | 点快速 tag「Class」 | 新增 class 属性 |
| F8 | 点快速 tag「点击事件」 | 新增 @click 属性 |
| F9 | 切到自由编辑 | 变成整块 textarea |
| F10 | 自由编辑写多行 key: value 后保存 | 属性批量生效 |
| F11 | 点红色删除按钮 | 节点从画布消失 |
| F12 | 画布属性面板只有 新增/保存/删除 三个按钮（复制兄弟在结构抽屉里才有） | 三个按钮 |
| F13 | ctrl+s | 等同点保存 |
| F14 | ctrl+d | 等同删除 |

## H. 右下浮圆

| H2 | 点 JS | JS 逻辑弹窗打开 |

## I. 代码预览弹窗

| # | 操作 | 预期 |
|-|-|-|

## J. JS 逻辑弹窗

| # | 操作 | 预期 |

## K. Vue 二次编辑

| # | 操作 | 预期 |
|-|-|-|
| K1 | 贴入完整 SFC 后解析 | 画布替换成该结构 |
